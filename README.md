# Makarapa Day — festival website

## Publish
Upload the entire contents of this folder to your GitHub Pages publishing directory. Keep index.html, social-investment.html, makarapabg.jpg and assets/ together. No npm, build step, CDN or backend is required.

## Hero
Replace makarapabg.jpg with your approved hero image using that exact filename. The included image is the supplied visual reference. IMPORTANT: its baked-in venue text says HIRO SHISANYAMA, while the requested website copy says UNIQ SHISANYAMA. Confirm the venue and replace the artwork before publishing. Do not rely on the gradient overlay to conceal that discrepancy.

## Page structure
index.html: hero, introduction, left-to-right ribbon, artist spotlight, hiking video, gallery, partnerships and ticket CTA.
social-investment.html: hiking video, Business Expo video, Top 8 Tournament, participation enquiries.
assets/site.css: responsive styling. Barlow Condensed headings; Barlow body text. No serif display font.
assets/site.js: mobile menu, pausable ribbon, keyboard-accessible gallery, single-video playback.

Email buttons open the visitor's mail client; no form pretends to submit. Source photography, artwork and videos were supplied or retrieved from makarapafestival.co.za and retain their original ownership. Review final event details and publication rights before launch.

## Accessibility
Semantic headings, descriptive image alternatives, visible focus, skip navigation, reduced-motion ribbon fallback, pause button, native video controls and modal Escape support. The supplied videos have no caption files; accurate captions should be added when available.
